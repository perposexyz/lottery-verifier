    How the draw works 
    1. At close the entries text (round, end, target slot, one line per player: account:wallet:tickets) is fixed and commit = sha256(entries) is published, together with a future Solana slot (~1 min ahead).
2. blockhash = hash of the first finalized Solana block at or after that slot. Nobody knows it at close; Solana validators do not know the entries.
3. seed = sha256(commit + ":" + blockhash). rand(n, m) = int(sha256(seed + ":" + n)) mod m.
4. k = min(places, players) winners: for n = 0..k-1 pick by tickets among those not drawn yet.
5. Places are shuffled (Fisher–Yates, i = k-1..1, j = rand(n, i+1), n continuing).
6. A removed winner's place is re-drawn with the next n among those never drawn.
